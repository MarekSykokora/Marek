## ⚡ NEJJEDNODUŠÍ CESTA (PRO KAŽDÉHO)

### Krok 1: Otevři AI (Gemini, ChatGPT, Claude...)
- Jdi na: https://gemini.google.com (nebo ChatGPT)
- Vytvoř nový chat

### Krok 2: Zkopíruj system prompt
- Jdi do souboru: `crypto-system-prompt.txt`
- **Zkopíruj VEŠKERÝ obsah** (Ctrl+A, Ctrl+C)

### Krok 3: Vlož do AI
- V AI nalepši (Ctrl+V): obsah z kroku 2
- Stiskni Enter
- ✅ Hotovo! AI teď "umí" kryptoměny!

### Krok 4: Testuj
Zkus napsat:
```
Vysvětli mi jak fungují smart contracts na Ethereu
```

nebo

```
Analyzuj tuto transakci: 0x1234...
```

## 📖 HLAVNÍ VLASTNOSTI PROMPTU

Prompt AI učí:

### 1. **BLOCKCHAIN ZNALOSTI**
- ✅ Ethereum, Bitcoin, Solana, Polygon, Base, Arbitrum, Optimism...
- ✅ EVM vs non-EVM sítě
- ✅ Consensus mechanisms (PoW, PoS, atd.)

### 2. **SMART CONTRACTS**
- ✅ Solidity (Ethereum)
- ✅ Rust (Solana)
- ✅ Vyper, Yul
- ✅ Bezpečnostní audit
- ✅ Common vulnerabilities (Reentrancy, Integer Overflow...)

### 3. **TECHNICKÉ DETAILY**
- ✅ JSON-RPC API
- ✅ ABI (Application Binary Interface)
- ✅ Transaction format
- ✅ Gas optimization
- ✅ Wallet interakce (MetaMask, atd.)

### 4. **BEZPEČNOST & COMPLIANCE**
- ✅ Risk disclaimers
- ✅ NOT financial advice
- ✅ Security best practices
- ✅ Regulatory awareness

### 5. **PRAKTICKÉ SCHOPNOSTI**
- ✅ Parsování transakcí
- ✅ Analýza kontraktů
- ✅ DeFi protokoly (Uniswap, Aave, atd.)
- ✅ NFT & Token standards
- ✅ Python příklady
- ✅ Zabraňuje "smyčkám" a lhání
